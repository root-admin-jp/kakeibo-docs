# ADR-0005 シークレット管理 — クレデンシャルはコミットしない

- 状態: Accepted (2026-11-07, 本人指定)

## 決定
実値は `.env` / 環境変数のみ。リポジトリには `.env.example` (ダミー値だけ) を置く。`.gitignore` で `.env`, `application-local.yml` 等を除外。CIが必要になったら GitHub Secrets を使う。GitHubのパスワード/トークンや金融機関の認証情報はチャットやコードに置かない。

## 理由
金融系アプリのため特に厳格にする。本人の明示指定。

## 影響
初回セットアップは `.env.example` をコピーして値を入れる手順になる。
